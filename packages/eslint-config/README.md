# @fossil-design/eslint-config

The shared ESLint config for [Fossil](https://github.com/ibrahimmoazzam/fossil), an open-source design system for agentic coding.

> **Not ready for use yet.** Versions 0.0.x reserve the package name and prove the release pipeline, and contain no working code. The config lands in Phase 5 of the [roadmap](https://github.com/ibrahimmoazzam/fossil/blob/main/PRD.md).

## What it will contain

- A ban on raw layout elements such as `<div>` in favour of `<Box as="…">`
- A written reason on every lint-disable comment
