# @fossil-design/stylelint-config

The shared Stylelint config for [Fossil](https://github.com/ibrahimmoazzam/fossil), an open-source design system for agentic coding.

> **Not ready for use yet.** Versions 0.0.x reserve the package name and prove the release pipeline, and contain no working code. The config lands in Phase 5 of the [roadmap](https://github.com/ibrahimmoazzam/fossil/blob/main/PRD.md).

## What it will contain

- Custom properties instead of raw colours, spacing, radii, fonts and durations
- Semantic tokens only, with primitive and deprecated names rejected
- Margins limited to `0`, so spacing comes from padding and `gap`
